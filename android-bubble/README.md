# DriveMeta — bolha de atalho (teste)

Este projeto Android é isolado da versão web principal do DriveMeta.

Função única do protótipo:
- pedir a permissão de aparecer sobre outros apps;
- mostrar uma bolha flutuante `DM`;
- permitir arrastar a bolha;
- ao tocar, abrir rapidamente o DriveMeta;
- permitir ativar ou desativar a bolha pelo app de teste.

A versão web/PWA original não é alterada por este teste.
